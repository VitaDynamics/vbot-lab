# Community & Support

<p align="center">English | <a href="README.zh-CN.md">中文</a></p>

Building with VBOT EDU robots, stuck on a problem, or exploring a new idea?
Join [Vbot 超能社区](https://forum.vbot.cn/) to ask questions, share applications,
and suggest improvements. A reproducible question helps others investigate and leaves
a useful answer for the next developer.

## Choose where to post

| What you need | Where to start |
| --- | --- |
| Help with device setup, connectivity, unexpected behavior, or Viewer problems | [帮助与反馈 · Help & Feedback](https://forum.vbot.cn/c/help/9) |
| SDK integration, robot applications, skills or Agent development discussions | [技能开发与 AI Agent · Skills & AI Agent](https://forum.vbot.cn/c/skills-agent/8) |
| A new capability or a product/workflow improvement | [灵感与建议 · Ideas & Suggestions](https://forum.vbot.cn/c/ideas/7) |
| A specific bug in this repository's code/examples or an incorrect document | [GitHub Issues](https://github.com/VitaDynamics/vbot-lab/issues), or a fix following [Contributing](../../CONTRIBUTING.md) |

For general usage questions, start in the community. Search for the feature name or
error first; add useful details to a relevant existing topic, or open one focused topic.
Use the category names shown on the forum. If a discussion identifies a repository bug,
link the forum topic from the issue rather than submitting the same report twice.

## Write a useful question

You do not need to find the cause before asking. Explain the task, what you expected,
and what actually happened. Start with the relevant [troubleshooting steps](../troubleshooting/README.md)
when possible, then include only the information needed to reproduce the issue.

Copy and fill in this template; omit fields that do not apply:

> **Title:** [Feature/tool] Short description
>
> - **Goal:**
> - **Robot model and relevant software/SDK version:**
> - **Environment:** OS, architecture, container; browser/version for Viewer issues
> - **Related guide / recipe / model filename:**
> - **Minimal reproduction steps or code:**
> - **Expected result:**
> - **Actual result and short error excerpt:**
> - **What I have already tried:**
> - **Sanitized screenshot or minimal log excerpt, if useful:**

Use a concrete title such as “Viewer: mesh missing after importing a URDF folder”
instead of “It does not work”. For code, include a minimal reproducible example rather
than an entire project. For connection problems, state the connection method and error
without publishing private network details. For a feature request, describe the use case
and desired behavior; a guessed API design is not required.

## Share safely

- Remove passwords, tokens, private keys, account details, device serial numbers and
  unrelated personal information. Do not upload EDU session configuration or credential dictionaries.
- Share short, reviewed excerpts instead of full logs, environment dumps or configuration bundles.
  Review screenshots for account details and other people's information.
- Share model files or application code only if you have permission to redistribute them.
- Do not repeat an unsafe robot operation just to obtain a recording. Stop the operation
  and describe the circumstances instead.
- Do not post vulnerability details or exploit steps in the community or public issues.
  See [Security](../../SECURITY.md) for the current reporting guidance.

## Follow up and share what worked

When you find a solution, reply in the original topic with the relevant change and
conditions under which it works. Share useful application ideas, model workflows and
development notes as well as problems. Avoid posting the same question across categories;
follow the [community guidelines](https://forum.vbot.cn/guidelines).

If a coding assistant helps with a report, ask it to summarize the goal, reproduction
steps, observations and remaining uncertainty. Review the text and attachments yourself
before posting. Preparing a draft does not authorize automatic posting or uploading logs.
