# 社区与支持

<p align="center"><a href="README.md">English</a> | 中文</p>

开发 VBOT EDU 机器人应用时遇到问题，建议优先在论坛搜索功能名称或错误信息。
未解决时，到 [Vbot 超能社区](https://forum.vbot.cn/)的相关帖子补充有效信息，
或新建一个聚焦的问题帖；也欢迎分享应用和提出改进建议。
一份可复现的问题描述，既便于大家一起定位，也能帮助后来的开发者找到答案。

技术支持也可通过 [vbot-edu@vbot.cn](mailto:vbot-edu@vbot.cn) 联系 VBOT EDU 团队。
支持范围包括设备配置与连接、开发环境、SDK／API 接入及应用问题排查。
邮件反馈时建议附上设备序列号（SN），便于识别设备并定位问题；
请勿在公开论坛或 GitHub Issue 中发布 SN。
来信请附上相关版本、复现步骤及下文说明的必要脱敏信息。

## 选择合适的反馈入口

| 需求 | 推荐入口 |
| --- | --- |
| 设备配置、连接、使用异常或 Viewer 问题 | [帮助与反馈](https://forum.vbot.cn/c/help/9) |
| SDK 接入、机器人应用、技能或 Agent 开发讨论 | [技能开发与 AI Agent](https://forum.vbot.cn/c/skills-agent/8) |
| 新能力需求、产品体验或开发流程改进 | [灵感与建议](https://forum.vbot.cn/c/ideas/7) |
| 明确属于本仓库代码／示例的缺陷或文档错误 | [GitHub Issues](https://github.com/VitaDynamics/vbot-lab/issues)，也可按[贡献说明](../../CONTRIBUTING.zh-CN.md)提交修复 |
| 技术支持邮件 | [vbot-edu@vbot.cn](mailto:vbot-edu@vbot.cn) |
| 疑似安全漏洞 | 按[安全说明](../../SECURITY.zh-CN.md)私下发送邮件至 [vbot-edu@vbot.cn](mailto:vbot-edu@vbot.cn)，不要公开发帖 |

板块名称以论坛展示为准。
如果讨论后确认是仓库缺陷，在 Issue 中关联原帖即可，不必重复提交两份完整报告。

## 如何提出一个便于解决的问题

不必先找到原因才能提问。说明你想完成的任务、预期结果和实际现象即可。
方便时先参考[排障说明](../troubleshooting/README.zh-CN.md)，再附上复现所需的最少信息。

可以复制下面的模板填写，不适用的项目直接省略：

> **标题：** [功能／工具] 简短描述
>
> - **想完成的任务：**
> - **设备型号与相关软件／SDK 版本：**
> - **环境：** 系统、架构、容器；Viewer 问题另附浏览器及版本
> - **对应指南／示例／模型文件名：**
> - **最小复现步骤或代码：**
> - **预期结果：**
> - **实际结果与简短错误信息：**
> - **已经尝试的方法：**
> - **必要的脱敏截图或最小日志片段：**

标题尽量具体，例如“Viewer：导入 URDF 文件夹后部分网格缺失”，而不是“用不了”。
代码问题提供最小可复现示例，无需上传整个工程；连接问题说明连接方式与错误，
不必公开私有网络细节。功能建议着重说明场景和期望行为，不需要先猜测接口设计。

## 安全地分享信息

- 公开发帖前，移除密码、令牌、私钥、账户信息、设备序列号（SN）及无关个人信息。
  不上传 EDU 会话配置或凭据字典。
- 用经过检查的短片段代替完整日志、环境变量或配置打包；截图也要检查账户及他人信息。
- 只有具备再分发权限时才分享模型文件或应用代码。
- 不为录制视频重复危险的机器人操作；先停止操作，再描述发生时的条件。
- 安全漏洞细节和利用步骤不要发到公开社区或 Issue，处理方式见[安全说明](../../SECURITY.zh-CN.md)。

## 解决后，也欢迎留下经验

问题解决后，请在原帖补充有效的方法和适用条件。除了问题，也欢迎分享应用创意、
模型使用方法及开发笔记。避免在多个板块重复发同一问题，遵循
[社区规则](https://forum.vbot.cn/guidelines)。

如果让编码助手协助整理反馈，可以请它归纳任务、复现步骤、观察结果与仍不确定的部分。
发帖前由你审阅正文和附件；生成草稿不代表允许自动发帖或上传日志。
