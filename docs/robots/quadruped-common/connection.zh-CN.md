# 机器狗有线连接与 SSH 登录

<p align="center"><a href="connection.md">English</a> | 中文</p>

四足机器狗（`foot_quadruped`）与四轮机器狗（`wheel_quadruped`）共用本页的有线连接、
网络配置和 SSH 登录步骤，用于完成电脑与设备通信，并使用 `vbot` 账户打开设备终端；
不涉及安装 SDK、部署应用或启动机器人运动。
本指南不适用于双足机器人（`foot_humanoid`）。
当前 EDU 发布范围仍仅为 `foot_quadruped`；连接方式相同不代表 `wheel_quadruped` 的
固件、SDK 或 API 已开放。

## 1. 连接网线

准备 USB-C 转网口适配器、网线，以及带网口或兼容网口适配器的电脑。
将机器人置于安全位置并保持静止。

<img src="assets/wired-connection.png" alt="机器人 USB-C 接口连接转网口适配器，通过网线连接开发者电脑" width="640">

图中以四足机器狗为例，四足与四轮机器狗的连接方式相同。
图中标注：**USB-C** — 机器人 USB-C 接口；**Ethernet Adapter** — USB-C 转网口适配器；
**Ethernet Port** — 以太网接口；**Developer Computer** — 开发者电脑。

1. 将 USB-C 转网口适配器插入机器人的 USB-C 接口。
2. 用网线连接适配器的网口与电脑的网口。
3. 开启机器人并等待启动完成，确认电脑能够识别有线连接。

网卡设置在电脑系统中完成，SSH 命令也在电脑终端执行；此步骤不需要启动开发容器。

## 2. 设置电脑网卡

在操作系统的网络设置中，选择与机器人相连的有线网卡，手动配置 IPv4：

| 配置项 | 配置值 |
| --- | --- |
| 电脑 IPv4 地址 | `192.168.126.100`（推荐） |
| 子网掩码 | `255.255.255.0`（前缀长度 `24`） |
| 网段 | `192.168.126.0/24` |
| 机器人 IPv4 地址 | `192.168.126.2` |
| 网关／路由器及 DNS | 电脑与机器人直连时留空 |

**不要将电脑地址设置为 `192.168.126.2`**，该地址由机器人使用。
如果使用其他电脑地址，请选择同网段内未被占用的主机地址。
只修改连接机器人的网卡，不要误改 Wi-Fi 或其他网络接口。
如果 VPN 或其他网卡已使用同一网段，请先解决路由冲突再连接。

## 3. 验证首次 SSH 登录

后续操作优先使用公钥免密登录。已有可用配置时，可跳过配置直接按第 4 节验证；
否则先建立可信的交互连接。示例使用有线地址 `192.168.126.2`，如设备实际 IP 或已配置的
SSH 别名不同，请统一替换。以下命令在电脑终端执行：

```bash
ssh vbot@192.168.126.2
```

用户名为 `vbot`，初始密码为 `vbot`；如果密码已经修改，请使用当前密码。
输入密码时，终端通常不会显示字符。

首次连接时，SSH 可能提示确认设备的主机密钥指纹，请核对指纹后接受。
后续若提示主机密钥发生变化，应先核实设备身份，不要关闭主机密钥检查。

登录后检查当前账户：

```bash
whoami
```

预期输出为 `vbot`。所有机器人出厂时的初始密码相同，同一网络中知道该密码的人都能登录。
如果账户仍在使用 `vbot`，请在当前会话中立即修改密码：

```bash
passwd
```

`passwd` 会先询问当前密码，再要求输入两次新密码。请为这台机器人单独设置密码并妥善保存：
第 4 节安装公钥以及公钥登录不可用时都需要它。机器人转交他人时请再次修改。

退出设备终端、返回电脑终端：

```bash
exit
```

请在可信局域网中使用此连接，不要将 SSH 或其他设备服务端口暴露或转发到不可信网络或互联网。

## 4. 配置公钥免密登录

以下命令在电脑执行，**不是在机器人的 SSH 终端执行**。示例使用 Linux／WSL 的
OpenSSH 工具和 `timeout`。在后续实际发起 SSH 的环境中配置并验证：宿主机登录成功，
不代表容器或另一个终端会话能访问同一密钥或 SSH agent。

### 选择密钥

优先复用已有的合适密钥对。没有可用密钥时再生成：

```bash
ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519 -C "vbot-dev"
```

此示例要求 `~/.ssh/id_ed25519` 和 `~/.ssh/id_ed25519.pub` 均未被使用。
不要覆盖已有密钥：需要复用时跳过生成，或选择未占用的文件名，并同步调整后续命令。
建议设置口令保护私钥。已有运行中的本地 SSH agent 时，加载一次密钥供后续操作使用：

```bash
ssh-add ~/.ssh/id_ed25519
```

没有 SSH agent 时，可使用操作系统提供的 agent，或在 Linux／WSL 中执行
`eval "$(ssh-agent -s)"` 启动，再执行 `ssh-add`。后续工具须继承该 agent 的访问环境
（`SSH_AUTH_SOCK`）。设备免密登录不要求私钥无口令，本地 agent 可使用受口令保护的私钥。
无需向机器人开启 agent 转发。

### 仅安装公钥

```bash
ssh-copy-id -i ~/.ssh/id_ed25519.pub vbot@192.168.126.2
```

提示输入设备账户密码时，在终端交互输入当前密码；初始密码为 `vbot`。
此配置将所选公钥添加到设备上 `vbot` 账户的 `~/.ssh/authorized_keys`，保留已有条目，
属于设备配置修改，不是只读检查。只安装 `.pub` 文件；私钥保留在电脑，不放进仓库。
公钥安装不可用或被拒绝时，停止并说明错误，不修改设备访问控制或 SSH 服务端设置。

### 验证非交互登录

核验并保存主机密钥指纹后，从后续实际操作所在的环境测试一次新的公钥认证连接：

```bash
timeout 10s ssh -i ~/.ssh/id_ed25519 \
  -o BatchMode=yes -o PreferredAuthentications=publickey \
  -o IdentitiesOnly=yes -o StrictHostKeyChecking=yes -o ControlPath=none \
  -o ConnectTimeout=5 -o ConnectionAttempts=1 \
  vbot@192.168.126.2 whoami
```

退出状态为 `0`、输出 `vbot`，且无需输入账户密码或私钥口令，才表示验证成功。
`ControlPath=none` 避免复用此前通过密码认证的连接。认证失败时检查所选密钥、
已安装公钥与本地 agent，不自动改用密码重试。SSH 不可达或连接被拒绝时，
停止后续操作，提示用户先按本指南连接设备或提供实际 IP，再继续。
主机密钥警告需单独核验设备身份，不关闭检查。

验证成功后，后续 SSH 命令复用选定的目标与密钥。使用 Aorta 或 ROS 2 前，先加载
[设备 shell 环境](../../getting-started/device-environment.zh-CN.md)。公钥配置不改变
`vbot` 账户权限，也不授权额外设备操作。仅咨询或离线检查不连接设备、不安装密钥。

## 连接排查

| 现象 | 检查项 |
| --- | --- |
| 未识别有线连接 | 机器人供电与启动状态、USB-C 适配器、网线以及电脑所选网卡 |
| 连接超时或无路由 | 电脑地址与子网掩码、地址冲突、VPN 及其他指向 `192.168.126.0/24` 的路由 |
| 连接被拒绝 | 确认地址并等待机器人完成启动；持续失败时检查设备版本是否支持 |
| 密码被拒绝 | 确认用户名为 `vbot`，并使用设备当前密码 |
| 公钥登录被拒绝 | 检查所选身份密钥、已安装公钥及本地 SSH agent，不回退到自动密码登录 |
| 主机密钥警告 | 接受新密钥前先核实设备身份 |
