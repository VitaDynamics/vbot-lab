# 机器狗共用传感器规格

<p align="center"><a href="sensors.md">English</a> | 中文</p>

以下列出适用于下述机器狗配置的传感器硬件参数。
本文是硬件参考，不是运行配置文件或标定文件。

## 适用设备类型

| 设备类型 | 构建标识 | 适用情况 |
| --- | --- | --- |
| 四足机器狗 | `foot_quadruped` | 适用于本文所述硬件配置 |
| 四轮机器狗 | `wheel_quadruped` | 共用本版传感器规格；其 EDU 指南尚未发布 |
| 双足机器人 | `foot_humanoid` | 不适用；独立规格待补充 |

本文是两类机器狗共用的唯一一份参数正文，不是所有 EDU 机器人的通用规格。
具体产品型号及硬件修订版本仍待明确，不能据此认定其他硬件配置也相同。
硬件参数适用范围不改变当前仅面向 `foot_quadruped` 的 EDU 发布范围。
各类型的发布范围与指南状态见[设备类型指南索引](../../robots/README.zh-CN.md)。

## 双目模组

| 参数 | 规格 |
| --- | --- |
| 安装位置 | 头部 |
| 分辨率 | 1920（H）× 1080（V） |
| 视场角（FOV） | 150°（水平）× 80°（垂直） |
| 双目基线 | 70 mm |

## 激光雷达

| 参数 | 规格 |
| --- | --- |
| 安装位置 | 头部 |
| 线数 | 16 线 |
| 测距范围 | 0.2–40 m |
| 水平视场角 | 360° |
| 垂直视场角 | 40.5°（−0.25°至 +40.25°） |
| 激光波长 | 905 nm |

## 红外摄像头模组

| 参数 | 规格 |
| --- | --- |
| 安装位置 | 腹部底面 |
| 输出分辨率 | 1536 × 1160 |
| 视场角（FOV） | 88° × 68° |

红外摄像头视场角的水平、垂直轴对应关系尚未明确，请勿根据上述数值顺序推断。

## 适用范围与限制
